# Система криптовалютных кошельков

Модуль для управления криптовалютными кошельками пользователей на сайте.

## Возможности

- ✅ Создание кошельков для различных криптовалют (Bitcoin, Ethereum и др.)
- ✅ Пополнение кошельков
- ✅ Вывод средств с кошельков
- ✅ Просмотр истории транзакций
- ✅ Безопасное хранение приватных ключей (шифрование)
- ✅ Поддержка нескольких криптовалют
- ✅ Тестовый режим для разработки

## Установка и настройка

### 1. Применение миграций

```bash
python manage.py migrate wallet
```

Это создаст необходимые таблицы в базе данных и добавит начальные криптовалюты (Bitcoin и Ethereum).

### 2. Настройка в settings.py

В файле `core/settings.py` уже добавлены настройки:

```python
# Настройки криптовалютных кошельков
WALLET_TEST_MODE = True  # В продакшене установить False
# WALLET_ENCRYPTION_KEY = 'your-encryption-key-here'  # В продакшене использовать переменную окружения
```

### 3. Тестовый режим

По умолчанию система работает в тестовом режиме (`WALLET_TEST_MODE = True`). В этом режиме:
- Генерируются случайные адреса и ключи (не реальные)
- Балансы генерируются случайно
- Транзакции создаются, но не отправляются в реальный блокчейн

### 4. Продакшен режим

Для работы с реальными блокчейнами:

1. Установите необходимые библиотеки:
```bash
pip install bitcoinlib  # Для Bitcoin
pip install web3 eth-account  # Для Ethereum
```

2. Установите `WALLET_TEST_MODE = False` в settings.py

3. Настройте подключение к блокчейну в `wallet/services.py`:
   - Для Bitcoin: настройте RPC подключение или используйте API
   - Для Ethereum: настройте Web3 провайдер (Infura, Alchemy и т.д.)

4. Установите ключ шифрования через переменную окружения:
```bash
export WALLET_ENCRYPTION_KEY="your-secret-key-here"
```

Или в settings.py:
```python
WALLET_ENCRYPTION_KEY = os.environ.get('WALLET_ENCRYPTION_KEY')
```

## Использование

### Создание кошелька

1. Перейдите на страницу `/wallet/`
2. Нажмите "Создать кошелёк"
3. Выберите криптовалюту
4. Кошелёк будет автоматически создан с адресом и приватным ключом

### Пополнение кошелька

1. Откройте детальную страницу кошелька
2. Нажмите "Пополнить"
3. Введите сумму
4. В тестовом режиме баланс обновится мгновенно
5. В продакшене необходимо отправить средства на адрес кошелька

### Вывод средств

1. Откройте детальную страницу кошелька
2. Нажмите "Вывести"
3. Введите адрес получателя и сумму
4. Подтвердите транзакцию
5. В тестовом режиме транзакция создаётся, но не отправляется в блокчейн

### Просмотр транзакций

- На странице кошелька отображаются последние 20 транзакций
- Все транзакции доступны в разделе "Все транзакции"

## Безопасность

⚠️ **ВАЖНО**: 

1. **Приватные ключи** хранятся в зашифрованном виде в базе данных
2. В продакшене обязательно используйте сильный ключ шифрования (`WALLET_ENCRYPTION_KEY`)
3. Регулярно делайте резервные копии базы данных
4. Используйте HTTPS для всех операций с кошельками
5. Ограничьте доступ к админ-панели Django

## Архитектура

### Модели

- `Cryptocurrency` - информация о поддерживаемых криптовалютах
- `Wallet` - кошельки пользователей
- `Transaction` - транзакции (пополнение, вывод, переводы)

### Сервисы

- `BlockchainService` - абстрактный базовый класс для работы с блокчейном
- `BitcoinService` - реализация для Bitcoin
- `EthereumService` - реализация для Ethereum
- `BlockchainServiceFactory` - фабрика для создания сервисов

### Добавление новых криптовалют

1. Создайте класс сервиса, наследующийся от `BlockchainService`
2. Реализуйте методы:
   - `generate_wallet()` - генерация кошелька
   - `get_balance()` - получение баланса
   - `create_transaction()` - создание транзакции
   - `get_transaction_status()` - статус транзакции
3. Зарегистрируйте сервис в `BlockchainServiceFactory`
4. Добавьте криптовалюту в базу данных через админ-панель или миграцию

## API Endpoints

- `GET /wallet/` - список кошельков
- `GET /wallet/create/` - форма создания кошелька
- `POST /wallet/create/` - создание кошелька
- `GET /wallet/<id>/` - детальная информация о кошельке
- `GET /wallet/<id>/deposit/` - форма пополнения
- `POST /wallet/<id>/deposit/` - пополнение кошелька
- `GET /wallet/<id>/withdraw/` - форма вывода
- `POST /wallet/<id>/withdraw/` - вывод средств
- `GET /wallet/transactions/` - список всех транзакций
- `GET /wallet/transactions/<id>/` - детальная информация о транзакции
